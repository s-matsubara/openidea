# OpenIDEA v0.1.37 VCS triage

Source: [OpenIDEA v0.1.37 release notes, Version control](https://github.com/l0ng-ai/openidea/releases/tag/v0.1.37#version-control). Historical feature assessment only. For current and future imports, follow the merge workflow in `../../openidea-upstream-merge/SKILL.md`.

| Upstream change                                         | Initial assessment                                                                                                                                                         |
| ------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Blame on both diff sides and history for selected lines | Candidate. Check whether jj annotation can target each snapshot or working-copy side. Check selected-line history separately.                                              |
| Git log graph lane fixes and expanded history views     | Candidate. Check shared graph calculations and the jj renderer separately. Keep the upstream Git renderer intact.                                                          |
| Push dialog commit details and scrollable commit list   | Candidate. Check the jj bookmark/tag preview model and preserve target selection semantics.                                                                                |
| Commit-message template                                 | Candidate. Check jj description templates and how they interact with the editor and saved drafts.                                                                          |
| Delete unversioned files from the Changes view          | Keep as an upstream Git feature. Ordinary jj working-copy files are tracked by snapshotting, so the Git unversioned-file action has no direct counterpart in this jj view. |
| Change Repository or Account before connection          | Inherit as-is if the integrated fork still uses the upstream path without a jj-specific change.                                                                            |
| Current worktree marker and faster Git log filtering    | Check whether the jj Workspaces list already marks the current workspace. Assess any missing UI behavior separately from Git-specific filtering optimizations.             |
