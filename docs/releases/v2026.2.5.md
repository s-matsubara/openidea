## Version control review

- Full message editing: add Edit Description to jj history. The multiline dialog
  starts with the complete description and preserves whitespace. The backend uses
  stdin, validates the selected immutable commit/change identities, and rejects
  stale rows rather than applying an edit to a replacement revision.
- Diff soft wrapping, line-ending badges, remembered diff window size, and Jump to
  Source improvements: inherit through the shared diff viewer used by jj.
- Multi-repository Push remote/target selection and branch sync indicators:
  inherit for Git. jj already has explicit remote/bookmark selection and its own
  push preview; Git target branches and upstream tracking are not jj identities.
- Git Log column dragging: inherit for the Git table. jj history uses a separate
  graph/list layout, so Git-specific table columns are not added to it.
- Batch branch deletion and deleting a holding worktree: inherit for Git. jj
  bookmarks and workspaces have independent lifecycles; deleting a bookmark must
  not implicitly remove a jj workspace. Existing jj workspace removal preserves
  snapshots and protects the active workspace.
