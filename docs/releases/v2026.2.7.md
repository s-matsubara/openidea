## VCS review and jj adaptations

- Native clipboard: shared Changes copy now uses the native clipboard bridge for
  jj as well as Git, retaining path deduplication, names, and selection order.
- Blame colours: jj annotations inherit per-commit gutter colours and matching
  commit highlighting. Keep jj author/revision/summary metadata, snapshot-aware
  refresh, and prohibit Git popup requests or Git Log navigation from jj rows.
  Git inherits the complete upstream commit popup and indexing improvements.
- SSH aliases: jj Git remotes receive the shared SSH host-alias resolution used
  by hosting integrations, while explicit jj root reads and Git mutation guards
  remain separate.
- Shared diff improvements: inherit caret visibility, draggable divider and
  source navigation for jj diff inputs. Git selection-following and file-chain
  toolbar navigation apply to Git change trees; jj retains its snapshot-aware
  working-copy preview rather than using Git/index-side diff identities.
- Root branch/sync decorations and push-target completion: inherited for Git.
  jj change identities/bookmarks are not Git upstream branches or Git ahead/behind
  counts, so these Git-only indicators are not fabricated for jj roots.
- Move Worktree and rewriting pushed Git commits: inherited for Git. jj already
  has its own workspace and rewrite operations, including stale identity checks
  and jj's immutable revision rules. No forced Git operations are enabled for jj.
