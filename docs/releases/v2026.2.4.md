## Version-control changes

| Upstream change                                          | Fork handling                                                                                                                                                                                                   |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Copy names/paths from Changes                            | Shared clipboard helper; jj adds Copy File Name, Cmd/Ctrl+C for names and Cmd/Ctrl+Shift+C for paths. Directory/multi-selection is supported; duplicate paths are omitted. No staging or rollback is performed. |
| GitHub commit checks in Log                              | jj uses the shared checks contribution and the full commit ID, with a visibility toggle. Remote discovery uses the jj Git backend for both colocated and non-colocated workspaces.                              |
| Branch actions in commit menu; explicit branch overwrite | Git changes inherited. jj already has New/Move Bookmark and New Tag actions using jj semantics and explicit names.                                                                                              |
| Worktrees grouped by repository and linked roots         | Git changes inherited. jj already selects a repository and lists its registered workspaces, including secondary roots. Git branch/worktree identities are not used for jj workspaces.                           |
| History past Windows command-line limits                 | Inherited for Git. jj reads history with jj templates and does not build the same oversized Git command.                                                                                                        |
| Stage/unstage error reporting                            | Inherited for Git; jj has snapshot-based working copies rather than Git staging.                                                                                                                                |
| Git Log performance and pack-directory invalidation      | Inherited in Git/shared graph code; jj retains its own history and snapshot readers.                                                                                                                            |
| Plugin commit workflow                                   | Inherited in Git commit flow; a Git staged commit is not equivalent to updating a jj description.                                                                                                               |
